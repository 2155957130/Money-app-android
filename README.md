# Money 账本

## 记账

- 手动记录收入、支出，选择存款或自由账户，填写日期、备注和自定义标签。
- 查看、筛选账单；修改备注和标签，撤销记录。
- 在账户之间转账，可填写手续费。
- 查看支出标签占比和月度报告。

## 分配

- 自定义分配项目、名称和占比，自动计算各项金额。
- 可按总资产、存款、自由余额或自填金额试算。

## 计划

- 创建存钱计划，设置目标金额或无上限、每日金额和提醒时间。
- 关联账户，实时查看进度；支持暂停、继续和达标结束。

## 我的

- 查看总资产、存款、自由和各明细账户，余额随记账、转账和收益同步更新。
- 创建和删除明细账户，查看资产分布。
- 为账户设置年利率、月利率、日利率、每日固定收益或自定义公式。
- 支持兴全货币 E 的公开基金收益估算；待确认收益可修改金额，再按实际到账确认或删除。

## 设置与隐私

- 管理自定义标签。
- 自动备份、手动导出和恢复预览。
- 应用锁、一键隐藏金额和计划提醒。

# 账本 1.8.11

个人安卓账本，狗爪图标。项目位于 `D:\Codex\money`，最新安装包为 `dist/Money-1.8.11.apk`。

## 官网

官网静态页面位于 `docs/`，可用 GitHub Pages 从 `main` 分支的 `/docs` 目录发布。下载按钮提供与 `dist/Money-1.8.11.apk` 相同的安装包。网站介绍为静态内容，不会上传或读取用户的记账数据。

## 安装和升级

支持 Android 8.0 及以上，需使用已更新的 Android System WebView / Chrome。将 APK 传到手机并打开，按系统提示允许该来源安装。

已有旧版的用户直接覆盖安装，**不要先卸载**。新版沿用相同包名和签名，保留原有账单、余额、标签、计划和备份。安装前可先在设置中导出备份。

## 四个板块

| 板块 | 功能 |
|---|---|
| 记账 | 手动收入/支出，选择存款/自由及具体明细账户，日期、备注、多选自定义标签，绿色收入/红色支出；修改备注和标签、筛选、撤销账单、转账与自定手续费、标签占比、页底月度报告 |
| 分配 | 自定义项目数量、名称、目标占比；输入或修改后自动计算；选择实时总资产、实时存款、实时自由，或自填金额试算；保存项目设置 |
| 计划 | 关联明细账户、目标/无上限、每日金额、提醒时间、转入或新增收入、实时进度、暂停/继续、达到目标自动结束 |
| 我的 | 总资产、存款/自由、明细账户及自定义收益规则，累计估算收益与资产分布 |

右上角设置统一管理标签、自动备份、恢复预览、应用锁以及通知/准点提醒权限；金额隐藏仅保留页顶眼睛按钮。

## 简约界面、转账与月度报告

收支页按“记一笔 → 账单记录 → 月度报告”排列；移除原顶部本月支出卡片。计划标题为“计划”，我的移除资产变化图与月报。页头标语、重复说明与设置页说明文案已精简，保留输入标签、账户与权限状态、错误提示和恢复确认。

标签可自建、重命名、删除，一笔收支可选多个标签。管理标签保留未提交的金额、日期和备注，标签修改不改变余额。

账户转账填写转入金额与手续费（默认零）；转出账户另扣手续费，转入账户收到完整的转入金额。例如转入 100 元、手续费 2 元，转出账户减 102 元、转入账户加 100 元、总资产减 2 元。手续费和转账存为一条流水，删除时一起撤销，余额不足时整笔不保存。旧版没有手续费的转账按零处理。

月度报告在收支页底部，可切换月份，显示收入、支出、结余、资产变化、月初/期末资产、估算收益、转账手续费、资产调整、记录笔数/天数和支出标签。手续费已计入支出，单独显示的手续费行为其中数，不能再次叠加。收支按账单日期，资产变化按实际入账日；多标签金额可能重叠，不能直接相加。

## 分配里的分类

金额来源是“用哪笔金额作为分配基数”：总资产为存款和自由之和，存款/自由各自读取对应全部明细账户的余额，自填金额用于任意金额试算。下方默认“存款 70%、自由 30%”只是可编辑的示例项目；可改为房租、餐饮、旅行等任意名称，也可以增减项目。各项占比合计 100% 后自动显示结果。修改金额来源、项目名称或比例不会执行转账或改变实际账户余额。

## 自动备份、恢复和隐私设置

- 自动备份默认开启，本机保留最近 14 天的快照。同一天的快照随保存更新，不是每笔操作都永久保留一份。
- 可在设置中通过系统文件夹选择器授权一个外部文件夹，自动写入 `账本-自动备份-日期.json` 并保留 14 天。根目录不允许选择时可新建“账本备份”文件夹；不需要授予整个手机存储空间的访问权限。外部写入失败时设置中会显示原因，本机快照仍单独保留。
- 本机快照随卸载/清除数据一起删除；选择的外部文件夹中的文件可在卸载后保留。停止关联外部文件夹不会主动删除其中已有文件。
- 恢复先预览当前/恢复后总资产、账户余额、账单/计划/标签数量，确认后才替换财务数据。恢复前额外保留当前账本的保护快照，最多保留 5 份。
- 应用锁使用手机系统的生物识别或锁屏密码，启用/关闭均需系统验证。Android 8～10 使用锁屏凭据，Android 11 及以上可使用受支持的生物识别或锁屏凭据。需先在手机系统中设置锁屏密码，账本不存储密码或生物信息。
- 冷启动需验证；离开应用可设置立即、30 秒或 1 分钟后重新验证，并立即遮挡页面。开启后启用系统截图/最近任务保护。锁定期间，原生接口也拒绝读取财务数据或保存修改。
- 金额隐藏从右上角眼睛按钮切换；它隐藏屏幕显示，不修改财务数据或备份文件内容。隐藏金额或开启应用锁时，提醒通知也不展示具体金额。
- 应用锁、金额隐藏、文件夹授权等是本机隐私设置，不会被恢复的财务备份覆盖。JSON 备份是明文文件，请保管在自己的位置。

## 统一的数据规则

所有实际金额以同一份账单流水为准：**明细账户余额 → 存款/自由汇总 → 总资产**。记账、转账、手续费、收益、关联计划、月报和分配的实时金额来源均读取这份数据。

- 新增明细可选择“从已有账户划入”，只重新划分钱所在的位置，总资产不变。此前没有记过的新资金才选择“新增资金”。
- 新增存款明细时，在同一个表单里选择计息方式；选择“微信零钱通 · 兴全货币 E”才使用该基金的收益规则。自建账户可在设置页删除：剩余余额划回同类基础账户，总资产不变；历史账单仍保留。关联计划或未来日期账单需先处理，待确认利息会移除。
- 账户内部转账不算收入或支出，总资产不变。金额按整数分保存，不能将账户余额扣为负数。
- 余额修改会保留调整记录，调整不计入本月收支。估算收益先进入“待确认利息”；确认后才增加余额并生成利息账单。
- 分配显示的是按照你设置的**目标占比**计算的规划结果。实时来源会随资产变化；自填金额仅用于试算，不会改动实际账户。
- 新建计划必须关联一个明细账户。计划从建立关联时的余额开始累计新增积累，之后该账户的收入、支出、转账和收益都会影响进度。取出资金可能使进度减少、使已达成计划重新进行。
- 向计划存入时，可记录“其他账户转入”或“实际新增收入”，直接生成共享账单。软件不执行银行转账。
- 旧计划的已有记录保留，升级时设置起点以延续原进度，不会凭空增加资产。历史“仅登记”记录仍可查看，其后使用关联账户继续积累。
- 修改某笔账单备注不会修改金额。已确认的收益可删除；实际到账不同时，以平台账单核对并调整账户余额。

## 每个账户自定义收益方式

在“我的 → 存款/自由 → 某个明细账户”中设置：

| 方式 | 每日估算规则 |
|---|---|
| 不自动计息 | 手动记录实际收入 |
| 年利率 | 计息本金 × 年利率 ÷ 365 或 360 |
| 月利率 | 计息本金 × 月利率 ÷ 30 |
| 日利率 | 计息本金 × 日利率 |
| 每日固定收益 | 每天增加自己填写的固定金额 |
| 自定义公式 | 自行输入每日收益公式，结果单位为元 |

利率方式支持是否复利。公式支持 `本金`、`余额`、`利率`、`基数`、数字、括号、加减乘除及百分号。例如 `本金 * 利率 / 基数 + 0.1`。在利率栏填写 `3` 代表 `3%`，公式中以 `0.03` 参与；“本金”不包括尚未支出的已入账收益，“余额”包含这些收益。公式结果须为非负数，分母为零等情况会记录计算错误且不入账。

按每个自然日的最终账户金额估算，在下一天结算前一天。后台每天调度；若应用被强制停止、关机或系统延后任务，下次打开会补算遗漏日期。每个账户保存结算日期，重复打开不会重复生成待确认利息；不足 1 分的收益以更小精度累计。公式出错时会暂停在出错日，修正后可以补算。

收益规则从设置当日起生效，不追溯修改已结算收益。手动补记旧日期的账单会在实际保存当日改变资产，不重算过去已经入账的收益。金额限制为总资产 900 亿元以内。

这些数字按你设置的规则估算，软件未连接银行、微信或其他平台，不代表对方的实际入账。可随时核对并调整明细余额。

## 提醒与本地数据

每日到设定时间，如果关联账户当天的净增加仍不足每日目标且总目标未完成，会发出系统通知。当天满足条件、目标达成、暂停或关闭提醒后，会取消相应提醒。收益结算本身不依赖通知权限。

Android 13 及以上需允许通知；Android 12 及以上的准点提醒需允许“闹钟和提醒”。关闭手机、强制停止应用期间无法通知，部分手机还需允许后台运行。不允许准点提醒时使用系统普通闹钟，可能延后，打开应用会核对并补算。

账本数据仅保存在本机，无登录，也不读取支付应用。仅为兴全货币 E（017269）获取基金官网公开的每日万份收益；按本机录入金额估算，不等于微信零钱通个人账户的实际到账。基金按日再投资，因此其待确认估算收益会参与后续基金收益估算，但确认前不增加账本余额。备份通过系统文件选择器导出为 JSON，恢复前会校验并要求确认。卸载/清除数据前请导出备份；备份为明文，请自行保管。`signing/` 内保存后续覆盖安装所需的同一签名密钥和密码，已加入 `.gitignore`，请备份而不公开提交。

1.8.11 账单明细限制显示高度，可在列表内直接上下滑动查看全部记录。

1.8.10 待确认利息可先修改金额并保存，仍保持待确认；重启和收益更新会保留修改，确认后按当前金额入账。收支页新增按月统计的支出标签占比，未标记支出单独显示；多标签支出分别计入各标签。

1.8.9 基金利息以次日入账日期命名和记录。例如 10 月 25 日产生的收益显示为“10 月 26 日利息”，同时标明 25 日计息；即使稍后才确认，账单也按 26 日归入月报。

1.8.8 逐笔确认基金待确认利息时可输入实际到账金额；账单、账户余额、总资产和月报使用实际金额，记录保留原估算金额。全部确认基金利息时会提示仍按估算入账。

1.8.7 缩小基金官网文件的下载范围，修复部分手机上“响应过大或超时”的失败提示。

1.8.6 修复基金官网当天已发布收益时同步失败的问题。应用缓存当天报价，但只结算到昨天；如果官网某天数据缺失，收支页会显示停算日期和“更新收益”按钮。官网补齐后会从停算日继续生成待确认利息。

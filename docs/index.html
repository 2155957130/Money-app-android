数据与隐私

自己的账，
留在自己的手机里。

账本无需账号。财务记录保存在手机本机，可使用应用锁、金额隐藏、自动备份与恢复预览。

收益按你设置的规则或基金公开数据估算，先进入待确认状态；你可以修改金额，再按实际到账确认。账本不会读取微信或银行账户，也不会自动获取你的实际到账金额。

本机保存应用锁备份与恢复
常见问题

用之前，先了解清楚。

账本会自动读取微信或银行卡流水吗？

不会。收入、支出和账户余额由你填写，账本不需要支付密码，也不会操作真实资金。

零钱通收益能和微信实际到账完全一致吗？

账本使用公开的基金收益数据，结合你记录的账户余额生成估算值。微信零钱通个人实际到账可能不同；待确认利息可以先修改，再按实际金额确认。

换手机后，数据怎么带走？

在原手机的设置中导出备份文件，再在新手机上使用恢复预览核对后导入。卸载应用或清除数据前，请先把备份保存到手机以外的安全位置。

旧版能直接更新吗？

可以直接安装新版覆盖同一应用。请勿先卸载旧版，更新前建议导出备份。

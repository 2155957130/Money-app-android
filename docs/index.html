02 / 分配
◫

先算好，再决定

随意增减分配项目，填写名称和占比。输入一个金额，立刻算出各项该分多少；也能直接按现有资产试算。

试算不会改变余额
03 / 计划
⚑

让存钱有进度

设置目标或无上限计划，关联账户与每天的存入金额。进度跟随真实账单更新，未达每日目标时按设置提醒。

达成目标自动结束

自己的账，

账本无需账号。财务记录保存在手机本机，可使用应用锁、金额隐藏、自动备份与恢复预览。

收益按你设置的规则或基金公开数据估算，先进入待确认状态；你可以修改金额，再按实际到账确认。账本不会读取微信或银行账户，也不会自动获取你的实际到账金额。
